# ملاحظاتي

تطبيق ملاحظات عربي بالكامل (RTL) يعمل في المتصفح فقط، دون خادم أو قاعدة بيانات خارجية. تُحفظ كل البيانات محليًا في `localStorage` داخل جهازك.

**النسخة المنشورة:** <https://gaeth200300-boop.github.io/mulahazati/>

## التشغيل

افتح الملف `index.html` مباشرة في المتصفح (نقرًا مزدوجًا)، أو شغّل خادمًا محليًا بسيطًا من داخل مجلد المشروع:

```powershell
python -m http.server 8000
```

ثم افتح: <http://127.0.0.1:8000>

> يُفضّل استخدام خادم محلي لضمان عمل جميع ميزات المتصفح بشكل موحّد، لكن التطبيق مصمم ليعمل أيضًا عند فتحه مباشرة من القرص.

## الحسابات والخصوصية

- أنشئ حسابًا جديدًا بالاسم والبريد الإلكتروني وكلمة المرور.
- تُشتق كلمة المرور باستخدام **PBKDF2-SHA256** مع ملح عشوائي فريد لكل حساب، ولا تُحفظ كلمة المرور نفسها إطلاقًا.
- كل حساب يملك مساحة ملاحظات معزولة تمامًا؛ لا يستطيع أي مستخدم رؤية ملاحظات غيره.
- الجلسة تُحفظ محليًا، لذا تبقى مسجّل الدخول عند إعادة فتح الصفحة حتى تسجّل الخروج.

## الميزات

- إنشاء وتحرير الملاحظات مع العنوان والنص والوسوم والألوان.
- تثبيت الملاحظات، وإضافتها إلى المفضلة، وإنشاء نسخة منها.
- الأرشيف والمهملات مع الاستعادة والحذف النهائي وإفراغ المهملات.
- بحث فوري، وتصفية حسب الوسم، وترتيب حسب التاريخ أو العنوان.
- عرض شبكي أو قائمة، مع حفظ التفضيل.
- اختصارات لوحة المفاتيح: `N` لملاحظة جديدة، `/` للبحث، `Ctrl+S` للحفظ، `Esc` للإغلاق.
- تصميم متجاوب بالكامل للجوال واللوحي وسطح المكتب.

## إعادة ضبط البيانات

لحذف جميع الحسابات والملاحظات المحلية، افتح أدوات المطوّر في المتصفح (F12) ونفّذ:

```js
localStorage.removeItem("mulahazati.db.v1");
localStorage.removeItem("mulahazati.session.v1");
localStorage.removeItem("mulahazati.layout.v1");
location.reload();
```

> تحذير: هذا الإجراء لا يمكن التراجع عنه وسيحذف كل الحسابات والملاحظات نهائيًا.

## بنية الملفات

```
index.html        واجهة التطبيق والترميز الدلالي
styles.css        نظام التصميم والتجاوب
js/core.js        التخزين والتشفير والأدوات المساعدة
js/auth.js        التسجيل وتسجيل الدخول والجلسة
js/notes.js       عرض الملاحظات والتصفية والأرشفة والمهملات
js/editor.js      محرر الملاحظة والوسوم والألوان
js/main.js        التهيئة والاختصارات ومزامنة التخزين
```

## ملاحظة أمنية

هذا تطبيق محلي بالكامل؛ الحماية هنا تهدف إلى فصل حسابات المستخدمين على الجهاز نفسه وليس إلى الحماية من شخص يملك وصولًا كاملًا إلى ملفات المتصفح. بيانات `localStorage` غير مشفّرة، لذا لا تستخدمه لأسرار حساسة على جهاز مشترك.
